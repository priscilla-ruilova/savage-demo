# 21 Savage, no authentication

A great way to practice writing and creating full stack apps. This code base is older and ripe for debugging. 

## How to navigate 

- Navigate to the deployed site
- Use the message board to submit messages in the list, autopopulated by backend logic
- Interact with the messages by using the thumbs up and thumbs down button to change the total likes number. 
- You have the option to delete messages as well! 

![screenshot of front page of login](/public/savageDemo.png)

## Features
- Frontend: HTML, CSS
- Backend: Node.js, express, MongoDB

## Installation for your own project

1. Clone repo
2. run `npm install`

## Installation

1. Clone repo
2. run `npm install`

## Usage

1. run `npm run savage`
2. Navigate to `localhost:3000`
